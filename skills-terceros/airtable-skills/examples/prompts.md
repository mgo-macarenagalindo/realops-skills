# Example Prompts

## Design from zero

```text
Design a professional Airtable base for managing grants, applicants, reviewers, scoring, approvals, payments, documents, and reporting. Provide Markdown documentation and an optional JSON blueprint.
```

## Spreadsheet normalization

```text
I have a spreadsheet with columns for client, project, task, owner, due date, invoice amount, and status. Convert it into a normalized Airtable architecture with tables, fields, linked records, views, forms, interfaces, automations, and migration steps.
```

## Audit

```text
Audit this Airtable schema. Find architecture problems, risky automations, field-type mistakes, permission risks, integration risks, and refactor steps.
```

## Automation design

```text
Create an Airtable automation spec for sending approved requests to an external API. Include trigger view, guard fields, idempotency, failure handling, retry strategy, and QA views.
```
