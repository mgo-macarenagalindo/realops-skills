# Polish / Finishing Touches

## Supercharge defaults
Replace plain-vanilla elements with enhanced versions of the same thing:
- **Bulleted lists** → icons (checkmarks, arrows, context-specific icons like padlock for security features).
- **Quotes/testimonials** → "promoted" with size and color, treated as visual elements.
- **Links** → heavier weight, color change, or custom thick partial-overlap underlines.
- **Form controls** → custom checkboxes/radios using brand color for selected states.

## Accent borders
A free design technique — colored rectangles in strategic spots:
- Across the top of a card
- Underneath active nav items
- Side of an alert message
- Short accent under a headline
- Across the top of the whole layout

## Decorate backgrounds
Plain pages benefit from background interest:
- **Change background color** to distinguish panels or page sections.
- **Slight gradient** for energy. Hues within ~30° of each other.
- **Subtle repeatable pattern** (e.g., Hero Patterns). Can repeat along one edge only.
- **Single shape or illustration** in a strategic spot — geometric shapes, partial patterns, simplified world maps.
- **Keep contrast low** so background decoration doesn't fight content.

## Empty states
- **Empty states are a priority, not an afterthought.** They are a user's first interaction with a feature.
- **Use an image or illustration** to grab attention.
- **Emphasize a call-to-action** that drives the next step.
- **Hide irrelevant supporting UI** (tabs, filters) until there's content for them to act on.

## Use fewer borders
When separating elements, try these *before* reaching for a border:
- **Box shadow** — outlines elegantly with less noise. Works best when the element's color differs from the background.
- **Two background colors** — adjacent elements with slightly different backgrounds need no border at all.
- **More spacing** — just push them apart.

If you already have differing backgrounds plus a border, try removing the border.

## Think outside the box
Common components have ossified shapes — break the mold:
- **Dropdowns** don't have to be a vertical list of links. Use sections, multiple columns, supporting text, colorful icons.
- **Tables** don't need one column per data point. Merge non-sortable related columns, add hierarchy, add images, add color.
- **Radio buttons** don't have to be circle + label. Selectable cards work great for important choices.

## Continuous improvement
- **Hunt for decisions you wouldn't have made.** When you like a design, ask: "What did they do here that I never would have thought of?" Those are the patterns to absorb.
- **Rebuild designs you admire from scratch, without peeking at devtools.** The discrepancies are how you discover the subtle rules (reduce heading line-height, letter-space your caps, combine multiple shadows, etc.).
